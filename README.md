# 2D Gravity Platformer — тестовое задание

2D-платформер, в котором персонаж ходит по поверхностям любой ориентации: гравитация направлена к ближайшей поверхности, а персонаж плавно поворачивается вслед за ней.

## Как устроено
- **GravityController** рейкастами находит ближайшую поверхность, берёт её нормаль как направление гравитации, прикладывает силу к `Rigidbody2D` и плавно разворачивает персонажа. Буферы для рейкастов выделяются заранее, поэтому в `FixedUpdate` нет аллокаций.
- **PlayerMovement** двигает персонажа относительно текущего «верха», а не мировых осей.
- **Ввод за абстракцией** `GameInputSystem`: отдельные реализации для клавиатуры и мобильных кнопок, геймплей не знает, откуда пришёл ввод.

## Стек
Unity 6, C#, Input System, URP 2D
